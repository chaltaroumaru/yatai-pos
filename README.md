# 屋台ドリンクPOS (yatai-pos)

屋台でお客さん自身にタップしてもらうセルフ注文用のPOS画面です。HTML1ファイルで動きます。

- シロップ(任意で1つ)+ 割る飲料・単品(1つ)を選ぶと左側に注文が表示されます
- ドリンクはすべて400円、アイストッピングありで+100円
- 「この1杯を確定して、もう1杯選ぶ」で複数杯の注文に対応
- 右上の「📋 会計履歴」で総会計・項目別の販売数・会計ごとの履歴を確認(端末のブラウザに保存)
- 右上の「⚙ メニュー編集」でシロップ・飲料の追加/変更/削除(端末のブラウザに保存)
- 右上の「🔗 連携設定」でグループチャットと連携(下記)

## グループチャットとの連携(全端末でリアルタイム共有)

[学祭グループチャット](https://github.com/chaltaroumaru/groupchat)と連携すると、次のようになります。

- 「会計完了」を押した注文が、グループチャットの「🧾 オーダー」画面にリアルタイムで届きます(プッシュ通知も届きます)。完了画面には注文番号が表示されます
- メニューと会計履歴を、連携した全ての POS 端末で共有します。どれかの端末でメニューを編集・会計すると、他の端末にもすぐ反映されます
- 会計履歴には、グループチャット側で付けた「未着手 / 作成中 / 提供済み」の状況も表示されます
- 電波が途切れても会計は端末に保存され(「未送信」と表示)、つながったときに自動で送信されます。同じ会計が二重に登録されることはありません

### 設定のしかた

1. グループチャットの管理者が「グループ設定 → POS連携」で「連携を始める」を押し、**サーバーの URL** と **接続コード** を確認します
2. POS の右上「🔗 連携設定」にその 2 つを入力して「保存して接続」を押します
   - グループチャット側で「POS の URL」を入力して作った「設定済みリンク」を POS 端末で開くだけでも連携できます
3. 画面上部に「🟢 〇〇 と連携中」と表示されれば完了です

> サーバーが `https://` の場合、POS も `https://`(GitHub Pages など)で開いてください。接続コードを再発行すると、古いコードの端末は「🔴 接続コードが無効です」と表示されるので入力し直してください。
